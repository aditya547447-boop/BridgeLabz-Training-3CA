Frontend:
Frontend is the part of a website that users can see and interact with. It is built using HTML, CSS, and JavaScript.
Example: Amazon product page.

Backend:
Backend is the server-side part of a website. It handles data, login, and database operations.
Example: Checking your username and password when you log in.

Full-Stack:
A full-stack developer works on both the frontend and backend.
Example: Building an entire shopping website.

## Client-Server Model

```
+-----------+        HTTP Request        +-------------+
|  Client   | -------------------------> |   Server    |
| (Browser) |                            |             |
|           | <------------------------- |             |
+-----------+      HTML/CSS/JS Response  +-------------+
```

### Explanation

- Client sends a request.
- Server processes it.
- Server sends the requested webpage.
- Browser displays the webpage.

Answer 3:
1. User enters a URL.
2. Browser finds the IP address using DNS.
3. Browser sends an HTTP request.
4. Server processes the request.
5. Server returns HTML, CSS, and JavaScript files.
6. Browser renders the webpage.
